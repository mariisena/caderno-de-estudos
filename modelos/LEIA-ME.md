# Pacote de modelos para o caderno de estudos

Este pacote contém a pasta `modelos/`, com 15 modelos em Markdown e um índice.

## Adicionar ao GitHub

1. Extraia o ZIP no computador.
2. Abra seu repositório e escolha **Add file → Upload files**.
3. Arraste a pasta `modelos/` extraída para a área de upload.
4. Confira os arquivos e salve em **Commit changes**.

Se já criou os quatro modelos anteriores, os nomes correspondem aos usados na conversa. Compare as versões antes de substituir, principalmente se fez alterações próprias. O fichamento continua com o nome `fichamento.md`.

O pacote não altera seu README principal nem sua licença.

Mensagem de commit sugerida: `docs: adiciona pacote de modelos de estudo e pesquisa`.

Para adicionar o índice ao README principal, use: `[Modelos de estudo](modelos/README.md)`.
