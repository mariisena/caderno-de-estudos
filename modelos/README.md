# 📚 Modelos do caderno de estudos

Modelos para apoiar anotações, leituras, prática e pesquisa. Escolha conforme a tarefa; não é necessário preencher todas as seções.

## Como usar

1. Abra o modelo e copie seu conteúdo.
2. Crie um arquivo na pasta do assunto, fora de `modelos/`.
3. Dê um nome descritivo, como `computacao/redes/modelo-osi.md` ou `pesquisa/fichamentos/2022-sobrenome-tema.md`.
4. Preencha com suas palavras e remova as seções que não se aplicam.
5. Cite as fontes e conecte notas relacionadas com links relativos.

Não altere o modelo original para registrar uma leitura específica: preserve-o para reutilização.

## Por onde começar

Para o dia a dia: anotação, resumo de aula, exercício e guia de ferramenta.
Para leituras: fichamento de artigo ou de livro/capítulo.
Para a pesquisa: diário, pergunta de pesquisa, reunião, análise de dataset e experimento, conforme necessário.
Para organização: plano de estudos, revisão semanal e registro de erro.

O caderno pode registrar o aprendizado e apontar para os scripts, dados e resultados do repositório da pesquisa, onde esses materiais são mantidos.

## Publicação

Separe citações literais das suas interpretações e inclua página ou seção quando disponível. Prefira links a cópias de materiais de terceiros. Revise informações pessoais, credenciais e registros internos antes de publicar.
